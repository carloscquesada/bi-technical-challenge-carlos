# AI Usage

I used AI assistance during this challenge for:

- dbt and DuckDB project setup guidance
- SQL syntax review and debugging
- discussing alternative metric definitions
- reviewing analytical edge cases
- documentation and README drafting

I manually reviewed the source data, selected and validated the business definitions, investigated data-quality discrepancies, executed and checked all queries, and validated the final results.

AI was used as a development and review tool rather than as a source of business truth.
